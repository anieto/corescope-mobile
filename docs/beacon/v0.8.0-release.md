# NodeScope 0.8.0 release copy

## Release status

Marked complete on 2026-10-15. The iOS and Android releases are pending approval
from Apple and Google, respectively.

## What's New

NodeScope now supports Beacon servers alongside CoreScope. Pick a Beacon community and browse the
live map, nodes, observers, recent packets, packet details, and confirmed routes.

On Beacon sources you can also:

- See each node's neighbors and the signal they're heard at.
- Open node analytics for up to seven days of activity, signal, packet types, and hop counts.
- View observer activity plus battery, noise floor, airtime, and uptime telemetry.
- Read channels the server decrypts, and load older messages.
- Run diagnostics that check each Beacon feature.

Where Beacon doesn't provide something, NodeScope says so instead of showing zero. This release
also improves source switching, live map updates, and empty states for quiet networks.

## Beta review notes

NodeScope is a read-only MeshCore network browser. Version 0.8.0 adds support for Beacon servers
alongside the existing CoreScope integration. No account or login is required.

To test Beacon support, open Settings and choose the Colorado Mesh source, then:

- Browse the map, nodes, observers, and packets.
- Open a node: Mesh Reach shows its neighbor count and Links lists its neighbors with SNR. Open
  Analytics and switch between 24h, 7d, and 30d.
- Open an observer to see observation counts, observation types, and telemetry cards.
- Open Channels and read a channel; scroll to the top and tap "Load older messages."
- Open Settings > Analyzer Diagnostics to see each Beacon capability checked.

Expected limitations, each shown with an explanation rather than empty or zero values:

- Beacon keeps about seven days of observation history, so longer ranges show the last seven
  days and are marked partial.
- Beacon node history doesn't identify observers or peers, so per-node availability, longest
  silence, signal grade, observer coverage, and peer interactions are unavailable.
- Channels that decrypt on the phone (added with a hashtag or private key) work only with
  CoreScope servers; they're hidden while a Beacon source is selected and return when switching
  back.

Suggested test server: `map.meshcore.coloradomesh.org`
