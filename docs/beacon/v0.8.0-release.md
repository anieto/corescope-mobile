# NodeScope 0.8.0 release copy

## What's New

NodeScope now supports both CoreScope and Beacon servers. Browse live mesh activity, nodes,
observers, recent packets, packet details, and confirmed routes from supported Beacon communities.
This release also improves source switching, diagnostics, live map updates, and empty states for
quiet networks.

## Beta review notes

NodeScope is a read-only MeshCore network browser. Version 0.8.0 adds support for Beacon servers
alongside the existing CoreScope integration.

To test Beacon support, open Settings, choose the Colorado Mesh source, and browse the map, nodes,
observers, and packets. Beacon analytics and channel-management features are intentionally
unavailable because the server does not expose that data. The app displays explanatory states in
their place.

Suggested test server: `map.meshcore.coloradomesh.org`

No account or login is required.
