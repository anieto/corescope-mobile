# NodeScope 0.10.2 release notes

Status: builds iOS 0.10.2 (1), Android 0.10.2 (versionCode 20), from `feature/learn-layer`.
Scope: the store notes cover everything in 0.10 so far (0.10.0 was never submitted; 0.10.1 was the first
public 0.10 release), so people updating from 0.9 see the whole picture. New in 0.10.2: the Learn layer
(info buttons, Glossary, Term Explanations setting), Monaspace Neon for titles, names and values, regrouped
Settings, more card contrast (iOS), three Recently Viewed items until expanded, and an Android fix for the
app freezing when a foldable folds or unfolds. Candidate Sites moves to a later release.

## App Store — What's New

New in 0.10: Node Planner. Check a link before you install hardware. Link Profile shows the terrain between two points, line of sight, Fresnel zone clearance and an estimated link margin, based on radio and antenna settings you can adjust. Touch & hold the map or a known node to place each point, and the path is drawn as a dashed line colored by how much clearance it has. Results are estimates, not observed links.

Find a node in the field: open any node or observer that has a location to get its distance and a compass heading toward it.

Learn as you go: tap ⓘ beside terms like SNR, hops, observers and Fresnel zone for a short, plain-language explanation, or browse them all in Settings → Glossary. Already know the lingo? Turn the buttons off in Settings → Display.

A fresh look:
• Titles, names and values now use Monaspace Neon
• Cards stand out more clearly from the background, in light and dark mode
• Settings is grouped into Display, Analyzer, and Help & Support
• Explore shows your three most recent items, with the rest a tap away

Also new:
• CoreScope region groups in the region filter
• Optional background texture (Settings → Display)
• Better iPad and dual-screen layouts
• The live feed reconnects quickly when you return to the app

Fixed:
• The route and region menus on the live map no longer jump while you scroll them
• Returning to live traffic after a replay keeps your map view instead of zooming out
• On iPad, the live map's controls are in the right place as soon as the app opens
• The last item in Settings no longer sits against the tab bar
