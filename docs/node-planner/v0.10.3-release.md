# NodeScope 0.10.3 release notes

Status: beta builds iOS 0.10.3 (3), Android 0.10.3 (versionCode 23) (first beta (2)/22), from `feature/live-map-options`.
The build numbers skip 0.10.3 (1) and versionCode 21, which the Candidate Sites branch used; Candidate
Sites moves to 0.10.6. Store notes to follow once testing is done and the branch is merged.

## TestFlight — What to Test

This build is all about the live map. Please try:

• Settings → Live Map → Realistic Propagation. The map collects a packet's reports from different observers for a few seconds, then animates its paths together. Does it feel right next to CoreScope's "Realistic" mode?
• Settings → Live Map → Group Nearby Nodes, turned off, on a busy mesh. Zoomed out, nodes that would sit on top of each other are thinned out so the map stays responsive. Is panning smooth, and does tapping a node open it quickly?
• Replays. Replays now play all of a packet's routes together by default; pick one route in the route menu to see just that one. Check the pace, the trail, the ringed observer markers and their names when zoomed in. Pan the map mid-replay; it should pause and carry on.
• Replays that leave your region. With a region selected, replay a packet that was also heard in another one. The route should carry on through that region's nodes, drawn faded, instead of jumping to all of its observers at once.
• Live traffic. Packets should no longer bounce back and forth between nearby nodes. Dashed lines mark hops the analyzer couldn't identify.
• Pause Live in the Live Packets panel. The list and the map should both hold, with a count of new packets. Tap Paused on the map's title, or Resume Live, to go back.
• Map Filters (regrouped) and the new Map Key, from Filters or the ⓘ beside them.
• Channels with a region chosen: each preview should match the latest message you see when you open the channel.

Also fixed: ⓘ explanations no longer get cut off at the edge of the screen.
