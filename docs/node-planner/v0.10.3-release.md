# NodeScope 0.10.3 release notes

Status: beta builds iOS 0.10.3 (2), Android 0.10.3 (versionCode 22), from `feature/live-map-options`.
The build numbers skip 0.10.3 (1) and versionCode 21, which the Candidate Sites branch used; Candidate
Sites moves to 0.10.4. Store notes to follow once testing is done and the branch is merged.

## TestFlight — What to Test

This build is all about the live map. Please try:

• Settings → Live Map → Realistic Propagation. The map waits a few seconds for every observer to report a packet, then animates all of its paths together. Does it feel right next to CoreScope's "Realistic" mode?
• Settings → Live Map → Group Nearby Nodes, turned off. Every node is drawn on its own. Is the map smooth while panning and zooming, and does tapping a crowded spot zoom in on it?
• Replays. Open a packet with several routes and choose All Routes in the route menu. Check the pace, the trail, the ringed observer markers and their names when zoomed in. Pan the map mid-replay; it should pause and carry on.
• Live traffic. Packets should no longer bounce back and forth between nearby nodes. Dashed lines mark hops the analyzer couldn't identify.
• Pause Live in the Live Packets panel. The list and the map should both hold, with a count of new packets. Tap Paused on the map's title, or Resume Live, to go back.
• Map Filters (regrouped) and the new Map Key, from Filters or the ⓘ beside them.
• Channels with a region chosen: each preview should match the latest message you see when you open the channel.

Also fixed: ⓘ explanations no longer get cut off at the edge of the screen.
