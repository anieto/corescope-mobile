# NodeScope 0.10.0 release notes

Status: iOS 0.10.0 (7) archived 2026-10-30, Android 0.10.0 (versionCode 18) built from `46bbaca`.
Store submission and approval are not recorded here.
Scope: Node Planner (Link Profile), Find a node, region groups, background texture, wide and
dual-screen layouts, live feed reconnect. iOS build 7 adds two live map fixes, and Android is
unaffected by them. Candidate Sites is 0.10.1.

## App Store — What's New

New in 0.10: Node Planner. Check a link before you install hardware. Link Profile shows the terrain between two points, line of sight, Fresnel zone clearance and an estimated link margin, based on radio and antenna settings you can adjust. Pick endpoints on the map or from known nodes, and the path is drawn as a dashed line colored by how much clearance it has. Results are estimates, not observed links.

Find a node in the field: open any node or observer that has a location to get its distance and a compass heading toward it.

Also new:
• CoreScope region groups in the region filter
• Optional background texture (Settings → Appearance)
• Better iPad and dual-screen layouts
• The live feed reconnects quickly when you return to the app

Fixed:
• The route and region menus on the live map no longer jump while you scroll them
• Returning to live traffic after a replay keeps your map view instead of zooming out
