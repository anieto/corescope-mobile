How to read this: colored cells are model estimates above the illustrative −130 dBm receiver threshold (152 dB path loss). The dashed circle is only the calculation boundary. Terrain remains visible beneath the overlay. Hover over colored cells for their estimated margin.

The selected area was computed independently and checked against matching cells from a larger 100 m grid. This preview uses the new feature-preserving algorithm; it is not the earlier fixed-profile preview.

Simulation assumptions: 915 MHz, 30 m transmitter height, 1.5 m receiver height, median inland conditions, zero clutter, 22 dBm combined link-budget numerator. Buildings, trees and actual radio performance are not verified. DEM interpolation cannot recover features missing from the terrain source.
