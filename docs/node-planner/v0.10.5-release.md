# NodeScope 0.10.5 release notes

Status: iOS 0.10.5 (1), Android 0.10.5 (versionCode 25), from `feature/node-check` (fast-forwarded to `main`).
Adds Node Check on top of 0.10.4. Candidate Sites and Estimated Coverage, which had used these numbers on
their own branch, move to 0.10.6.

## TestFlight — What to Test

This build adds Node Check: is your node getting out? Please try (CoreScope sources):

• Explore → Node Check. Look up a node by name, public key or a contact link shared from the MeshCore app. With several matches, pick yours; your favorite nodes are listed for one tap.
• A node’s page. The new Node Check card shows its verdict. Tap it for the full check: what’s working, what to look at, and what to do about it.
• Run Live Test. Send a flood advert from your node and watch observers report it as it happens, with a map. Try it with a repeater and with a companion.
• A brand-new node. Enter its full public key. If the analyzer hasn’t heard it yet, start a live test and watch for its first advert.
• Who heard its last advert, grouped by region. Does the list make sense for where your node is?

Beacon sources explain that Node Check needs CoreScope for now.

## App Store — What's New

New: Node Check. Is your node getting out? Look up any node, or open the card on a node’s page, to see when observers last heard it, how far its last flood advert reached, which observers hear it directly, whether a repeater is relaying, and whether its clock is right, with what to do when something looks off.

Run a live test: send a flood advert and watch observers report it as it happens, on a map. It works for a brand-new node too, so you can see its very first advert land.

Node Check works with CoreScope sources.
